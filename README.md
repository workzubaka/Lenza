# Lenza Messenger Repository

Welcome to the repository for **Lenza** corporate messenger deployment.

## 📌 About the Project
Lenza is a corporate messenger designed for effective team communication. This repository is used for hosting installer files and related documentation.

## 🚀 How to Download the App
Do not try to download the `.exe` file from the main folder structure. Instead, go to the **[Releases](https://github.com/workzubaka/Lenza/releases)** section on the right side of this page and download the latest stable version.

## 💻 System Requirements
* Windows 10 / 11 (64-bit)
* Active internet connection
